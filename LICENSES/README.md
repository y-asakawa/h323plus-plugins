# License Texts

This directory contains unmodified standard license texts referenced by source
files or external dependencies described in this repository.

The texts were retrieved on 2026-06-24 from the SPDX License List Data
repository:

https://github.com/spdx/license-list-data/tree/main/text

The filename identifies the SPDX expression represented by each copy. License
version options come from the applicable source file or dependency terms.

These generic texts do not replace copyright-holder-specific acknowledgements,
custom permissions, patent notices, or other conditions in source-file
headers. See [`../THIRD-PARTY-NOTICES.md`](../THIRD-PARTY-NOTICES.md).
